# Device Access Deployment Assets

This directory contains deployable templates and generated audit artifacts for
the Later cross-device SSH control plane.

## Source of truth

- `../../ops/device-inventory.json` — real non-secret inventory
- `../../ops/device-inventory.schema.json` — schema v2 contract
- `../../ops/device-public-keys/` — public keys only; private keys never belong here

## Files

- `ssh-config` — generated by `scripts/render-device-ssh-config.sh`; do not edit
- `install-cloud.sh` — inventory-driven cloud accounts and SSH restrictions
- `macos/com.later.device-relay.plist.in` — macOS relay template
- `linux/later-device-relay.service.in` — Linux user relay template
- `cloud/60-later-device-access-hardening.conf` — public-key-only cloud SSH baseline
- `workspace-AGENTS.md` — cross-project agent instructions

## Required workflow

```bash
./scripts/device-access.sh check
./scripts/render-device-ssh-config.sh --output deploy/device-access/ssh-config
./scripts/test-device-access.sh
./deploy/device-access/install-cloud.sh --plan
```

Only after reviewing the plan should an operator run `install-cloud.sh` as root
on the bastion. Full onboarding, rollback and key rotation instructions are in
`docs/device-onboarding.zh-CN.md`.
